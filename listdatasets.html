INICIANTE • PYTHON • PANDAS

Datasets para começar a aprender Análise de Dados

Uma coleção selecionada para estudantes que estão começando com Python, Pandas, estatística e visualização de dados. Comece com dados simples, faça perguntas, limpe os dados e desenvolva sua primeira análise.

Nenhum dataset corresponde à sua pesquisa.
Os links "Abrir no Kaggle" levam às páginas originais dos datasets. Os botões "Baixar" levam aos arquivos armazenados no Google Drive. Verifique a licença e os requisitos de atribuição de cada dataset antes de redistribuí-lo.
